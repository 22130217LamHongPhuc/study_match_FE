sequenceDiagram
    actor User
    participant FE as Frontend (Forgot/Reset Page)
    participant AC as AuthController
    participant AS as AuthService
    participant UR as UserRepository
    participant PR as PasswordResetTokenRepository
    participant MS as MailService

    User->>FE: Enter email
    FE->>AC: POST /api/auth/forget-password (email)
    AC->>UR: findByEmail(email)
    UR-->>AC: User / USER_NOT_FOUND

    alt Forget password success
        AC->>AS: saveForgetPasswordToken(user)
        AS->>PR: disableAllValidTokens(userId)
        AS->>PR: save(PasswordResetToken UUID, 15 min)
        AS-->>AC: PasswordResetToken
        AC->>MS: sendMailTo(email, reset-password, link)
        MS-->>AC: Email sent (link: /reset-password?token=)
        AC-->>FE: ApiResponse (success=true)
        FE-->>User: navigate(/check-email)
    else Failed
        AC-->>FE: Error USER_NOT_FOUND
        FE-->>User: toast.error
    end

    User->>FE: Open /reset-password?token=...
    FE->>FE: Enter newPassword + confirm<br/>validate length >= 8, match
    FE->>AC: POST /api/auth/reset-password (token, newPassword)
    AC->>AS: resetPassword(newPassword, token)
    AS->>PR: findByToken(token)
    AS->>AS: check not used / not expired
    AS->>UR: findById + BCrypt encode password<br/>set used=true, save user

    alt Reset success
        AC-->>FE: ApiResponse (success=true)
        FE-->>User: navigate(/reset-password-success)
    else Reset failed
        Note over AS,PR: INVALID_TOKEN / TOKEN_USED / TOKEN_EXPIRED
        AC-->>FE: Error response
        FE-->>User: show error
    end
